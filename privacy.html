Privacy Policy

Last updated: 2026-10-28

What Jacopo is

Jacopo is a private personal assistant used by a single person, its owner. It is not offered to the public and has no other users.

Data accessed

With the owner's consent through Google OAuth, Jacopo accesses only the Google account p5studio.jacopo@gmail.com, which belongs to the assistant itself. It may read and send email, and create and manage calendar events, contacts, documents, spreadsheets and Drive files in that account. It does so only to carry out tasks the owner asks for.

How data is used

  • Data is used only to perform the owner's requests: reminders, meeting invitations, emails, translations and documents.
  • Data is not sold, rented or shared with third parties for advertising or any other purpose.
  • To understand requests and generate text, relevant content is processed by the owner's large language model provider (OpenAI) under that provider's terms.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

OAuth tokens and working files are stored on the owner's private server with access restricted to the assistant's system account. Backups stay on the same server.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
